## Confirmed bugs (evidence-backed)

1. **Search dead at list root** — `AssetController::browsePayload()` returns `assets=null`
   unless `level`+`node` present, so `/assets?search=laptop` shows "Tidak ada hasil" + total 0
   while 5 laptops exist inside clusters. Breaks FR-04.1 for layperson flow.
2. **Tipe filter "Semua Tipe" zeroes results** — `AssetTypeFilter` has
   `<SelectItem value="all">`; backend `where('asset_type','all')` → total 0 (verified via
   `json=1`). Type says `'' | 'fixed_asset' | 'equipment'` but UI emits `'all'`.
3. **View toggle dead until reload** — `useLocalStorage` `set()` writes `value` state +
   storage, but render reads `hydrated ? cached : value`; `cached` never updated on set →
   clicking Kartu does nothing until F5 (verified in DOM + reload).
4. **Mobile bottom nav stacked (262px tall)** — `mobile-bottom-nav.tsx` renders
   `<div className="grid-cols-4">` without `grid` → links stack full-width; nav covers
   content half the screen.
5. **Bulk toolbar hidden on mobile** — toolbar z-40 bottom-64px sits fully inside the
   262px nav (z-50) → Hapus massal unreachable on phone. P2 failure.
6. **"Cetak yang dipilih" dead menu item** — `DropdownMenuItem` has no onClick; enabled once
   selection > 0, does nothing.
7. **"Filter" button clears filters** — `asset-filter-bar.tsx` Filter button
   `onClick={onClearFilters}`, duplicate of adjacent X reset. Label promises opening filters.
8. **return_to loses list state** — Show back-link used `assetListUrl()` saved
   `/assets` plain (query-less snapshot at mount) → drill-down filter dropped.
9. **Show/Create/Edit/Scan still legacy** — `noon dark` wrapper + VibrantBackground
   violet/blue gradients + white/10 glass header cards → light theme renders dark legacy
   cards next to light shell (screenshot-confirmed). Tickets 06/07 scope.
