## Temuan P0

### P0-1 — Session key mismatch: user non-bypass melihat 0 aset

| | |
|---|---|
| Ditulis | `EmployeeSessionResolver.php:63` → session `employee` dengan key **`id_department`** |
| Dibaca | `AssetController.php:77` → key **`department_id`** |

Key tidak pernah cocok → `getEmployeeDepartmentId()` selalu `null` → `applyDepartmentFilter()` menjalankan `whereRaw('1 = 0')` (`AssetController.php:112`).

**Dampak:** seluruh role non-bypass melihat daftar aset kosong; `show`/`update`/`delete` membalas 403 (`:132`).

**Kenapa test tetap hijau:** `tests/Feature/AssetControllerGateTest.php:64` menanam session `['department_id' => ...]` secara manual, tidak lewat resolver. Test menguji kontrak yang berbeda dari produksi.

### P0-2 — Angka pengelompokan tidak difilter department

Ledger sudah benar (`:205`), tetapi bagian **"data yang dikelompokkan"** belum:

| Lokasi | Isi |
|---|---|
| `:316-330` | `withCount('assets')` pada group/category/cluster/sub-cluster tanpa scope |
| `:266-268` | `unclassifiedCount` global |
| `:222` | `directCount` global (mempengaruhi fallback descendant) |

**Dampak:** badge jumlah aset per klasifikasi menampilkan angka seluruh tenant, dan perilaku "kosong/tidak kosong" membocorkan keberadaan aset department lain.

### P0-3 — Daftar role bypass tidak cocok dengan ketentuan

| | Role |
|---|---|
| Ketentuan | `staff-asset` (asset-staf), `super-admin`, `admin-ho` |
| Kode (`:61-67`) | `manajer-pusat`, `super-admin`, `staff-asset`, `staff_asset`, `Asset Staff` |

- **`admin-ho` tidak ada** di tabel `roles`.
- `manajer-pusat` mendapat bypass padahal tidak disebut di ketentuan.
- Role `super_admin` (underscore, ada di DB) tidak dikenali bypass dan tidak dihitung `isSuperAdmin()` (`User.php:44`).

Isi tabel `roles` saat ini: `administrator`, `akunting`, `manager`, `staff-asset`, `super_admin`, `super-admin`.

## Rekomendasi (urut prioritas)

1. Normalisasi kontrak session ke satu key (`department_id`) + test login lewat resolver, bukan menanam session manual.
2. Satu sumber kebenaran aturan ini: hidupkan `config/asset_filters.php` (mis. `bypass_roles`) atau buat service `DepartmentScope`; hapus 3 daftar hardcoded.
3. Terapkan filter ke semua counts: `withCount(['assets' => fn ($q) => $this->applyDepartmentFilter($q)])`, `unclassifiedCount`, `directCount`.
4. Auto-assign department saat create untuk non-bypass + backfill `department_id = NULL`.
5. Batasi dropdown department ke department sendiri untuk non-bypass.
6. Putuskan eksplisit cakupan ketentuan: hanya `/assets` atau seluruh modul asset.
7. Test matrix: (bypass / non-bypass ber-department / non-bypass tanpa employee) × (ledger, counts, unclassified, scan, label, export, show 403).
